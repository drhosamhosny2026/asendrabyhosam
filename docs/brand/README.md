## Purpose

This folder is the **single source of truth** for ASCENDRA's brand, messaging, service architecture, and website strategy.

`BRAND_STRATEGY_v1.1.md` is the authoritative reference. **All future decisions** — copy, service packaging, information architecture, positioning, and visual direction — must be derived from it.

> ⚠️ **Archived files are preserved for historical reference only.** They reflect a previous positioning (the "Digital + Consulting" two-pillar era) and **must not be used as the source of current brand decisions.** When an archived document conflicts with `BRAND_STRATEGY_v1.1.md`, the strategy document always wins.

## Reading Order

Read these documents in sequence before doing any work on ASCENDRA:

1. **`BRAND_STRATEGY_v1.1.md`** — The constitution. Who we are, who we serve, what we believe, how we speak.
2. **`MESSAGING_AUDIT.md`** — Page-by-page review of the current website against the new positioning (Keep / Rewrite / Remove / Add).
3. **`SERVICE_ARCHITECTURE_DRAFT.md`** — How services are repackaged as integrated *systems* (in progress).
4. **`WEBSITE_RECONSTRUCTION_PLAN.md`** — The plan to realign the website with the strategy (in progress).
