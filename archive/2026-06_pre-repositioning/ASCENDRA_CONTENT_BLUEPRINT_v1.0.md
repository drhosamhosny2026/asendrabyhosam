# ASCENDRA UX CONTENT BLUEPRINT v1.0
### Page-by-Page Production Content — All Five Pages

**Status:** Production-Ready Draft
**Sources:** ASCENDRA_MASTER_BRIEF_v2.0 · ASCENDRA_IA_v1.1 · messages/en.json · messages/ar.json
**Purpose:** This document is the content layer between Information Architecture and Visual Design. Every headline, body paragraph, CTA, and label is written to final production standard. Feed this directly into design and development.

**Content Rules:**
- All English copy is final unless marked `[TBD — client content required]`
- All Arabic copy follows Modern Standard Arabic (MSA) — no dialect
- Arabic localization notes appear at the end of each section where relevant
- No copy in this document is approximate — every line is intentional
- Brand voice: Strategic. Executive. Precise. Premium. No hype.

---

## HOW TO READ THIS DOCUMENT

Each section entry follows this structure:

```
SECTION NAME
  Type           — structural role
  Visual Intent  — what the design layer should communicate
  Imagery        — specific asset or screenshot direction
  ─────────────────────────────────────────────────────
  Eyebrow        — small uppercase label (Inter, 0.16em tracking, gold)
  H1 / H2        — primary heading (Cormorant Garamond, Semibold)
  Sub-headline   — supporting statement (Inter or Cormorant, smaller weight)
  Body           — full written paragraphs
  CTA Primary    — primary action (gold button)
  CTA Secondary  — secondary action (ghost/outline or text link)
  ─────────────────────────────────────────────────────
  AR Note        — Arabic localization guidance where relevant
  Content Notes  — any constraints, special treatment, or dependencies
```
